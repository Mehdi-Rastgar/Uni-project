# سیستم آموزشی جامع دانشگاه

پروژه فول‌استک: **React (Vite)** + **Express** + **SQLite**

هر ۳ نقش (دانشجو، استاد، کارشناس آموزش/ادمین) به‌طور کامل پیاده‌سازی شده‌اند.

## ساختار پروژه

```
university-system/
├── backend/
│   ├── db/            schema.sql, database.js, seed.js
│   ├── routes/         auth.js, courses.js, professor.js, admin.js
│   ├── middleware/     احراز هویت JWT (requireAuth, requireRole)
│   └── server.js
└── frontend/
    └── src/
        ├── pages/                 Login, Dashboard (نقش‌محور)
        ├── pages/ (دانشجو)         RegisterCourses, Schedule, Transcript
        ├── pages/professor/       ClassList, GradeEntry
        ├── pages/admin/           CourseManagement, SemesterManagement,
        │                          ProfessorManagement, Reports
        ├── components/            Layout (نوار کناری نقش‌محور), ProtectedRoute
        ├── context/               AuthContext
        └── api.js                 کلاینت کامل ارتباط با بک‌اند
```

## پیش‌نیاز

- Node.js نسخه **۲۲.۵ یا بالاتر** (برای پایگاه‌داده از ماژول توکار `node:sqlite` استفاده می‌شود — نیازی به نصب هیچ پکیج جداگانه یا کامپایلر C++ نیست)

## راه‌اندازی

### بک‌اند
```bash
cd backend
npm install
cp .env.example .env
npm run seed     # فقط بار اول — ساخت پایگاه‌داده و داده‌های نمونه
npm run dev      # http://localhost:4000
```

### فرانت‌اند (در ترمینال جدا)
```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
```

## یوزکیس‌های پیاده‌سازی‌شده

**دانشجو (آموزشی):** احراز هویت (۰) · ثبت‌نام دروس (۱) · برنامه هفتگی (۲) · کارنامه (۳)
**دانشجو (مالی):** پرداخت شهریه · کارنامه مالی · لیست پرداخت‌ها
**استاد:** ثبت نمره (۴) · لیست کلاسی (۵)
**ادمین:** مدیریت دروس (۶) · مدیریت ترم + شهریه (۷) · مدیریت اساتید (۸) · گزارش‌گیری (۹) · مدیریت مالی

نکات مهم منطق کسب‌وکار:
- ثبت‌نام دانشجو پیش‌نیاز و ظرفیت را بررسی می‌کند.
- ورود ناموفق پس از ۵ بار، حساب را ۵ دقیقه قفل می‌کند.
- نمرات تا وقتی ادمین آن‌ها را «قطعی» اعلام نکرده، توسط استاد قابل ویرایش‌اند و در کارنامه دانشجو «در انتظار ثبت» نمایش داده می‌شوند.
- گزارش کارنامه کلی فقط بر اساس نمرات قطعی‌شده محاسبه می‌شود.
- هر ترم یک مبلغ شهریه ثابت دارد (توسط ادمین در «مدیریت ترم» تنظیم می‌شود). دانشجو می‌تواند به‌صورت کامل یا جزئی پرداخت کند.
- **پرداخت شهریه کاملاً شبیه‌سازی‌شده است** — به هیچ درگاه بانکی واقعی وصل نیست و صرفاً برای نمایش جریان کار در محیط دمو/پروژه دانشگاهی است. هر پرداخت بلافاصله «موفق» ثبت می‌شود و یک کد پیگیری ساختگی دریافت می‌کند.

## نکات فنی

- پایگاه‌داده SQLite در `backend/db/university.db` (به‌صورت خودکار ساخته می‌شود).
- رمزهای عبور با `bcryptjs` هش می‌شوند.
- احراز هویت با JWT (اعتبار ۸ ساعت)، توکن در `localStorage` مرورگر.
- برای شروع دوباره از صفر: فایل `university.db` را حذف و `npm run seed` را دوباره اجرا کنید.

## پیشنهاد برای ادامه (فاز بعدی)

- اتصال واقعی به درگاه پرداخت بانکی (در حال حاضر شبیه‌سازی‌شده است)
- خروجی PDF/Excel واقعی برای گزارش‌ها و رسید پرداخت
- صفحه ویرایش/حذف دروس و اساتید (در حال حاضر فقط افزودن و ویرایش جزئی پیاده‌سازی شده)
- تست‌های خودکار (Jest / Vitest)
